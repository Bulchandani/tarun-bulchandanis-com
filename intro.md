## Things built

### Meridian — internal AI-native enterprise architecture platform

- **Stack:** Next.js 15, TypeScript, FastAPI, PostgreSQL on Azure, Prisma, Microsoft Entra ID SSO, Vercel AI SDK with Google Gemini, Docker on Azure App Service
- **What it does:** Consolidates an EA repository, a PMO and portfolio-management tool, a compliance tracker, and manual spreadsheets into one query-able AI-native platform with a conversational assistant over the full portfolio context
- **Savings:** approximately $170,000/year in licence and admin savings at steady state
- **Case study:** https://tarun.bulchandanis.com/blog/case-study-meridian/

### CANVAS — Central Application aNd Vendor Approval System

- **Stack:** Nuxt 3, Vue 3, TypeScript, Flask (Python), SQLAlchemy, Pydantic v2, PostgreSQL on Azure, Microsoft Entra ID via Authlib, Celery + Redis, Microsoft Graph API, Azure OpenAI (gpt-4o, EEA), WeasyPrint
- **What it does:** Ten-step workflow from application intake through contract signing — Build/Buy/Extend decision, market research, vendor evaluation, parallel reviews (DPIA, Serviceability, Cybersecurity), AGB approval, SLT approval (via single-use email token), contract negotiation, contract signing. Append-only audit log, AI-generated architecture memos, full Microsoft Graph email and Teams integration
- **Architecture pattern:** Modular monolith. Built by a single full-stack developer to a six-month MVP target. Now folded into Meridian as a first-class surface
- **Case study:** https://tarun.bulchandanis.com/blog/case-study-canvas/

### Springboard — AI-native job-search platform

- **Stack:** Next.js 15, Drizzle, Supabase, GitHub Actions, Playwright, Gemini computer-use, Anthropic Claude
- **What it does:** Monitors approximately 1,400 companies, evaluates roles against a six-block rubric, generates tailored CVs and cover letters and interview prep, auto-fills applications across four interchangeable plans. Stops one click before Submit
- **Scale:** Approximately 15,000 lines of code, one engineer, approximately $4/month in total LLM and infrastructure cost
- **Case study:** https://tarun.bulchandanis.com/blog/case-study-springboard/
